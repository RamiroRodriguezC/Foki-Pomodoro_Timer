# Foki — Pomodoro + Task Timer

App de foco tipo Pomodoro con gestor de tareas minimalista. Mobile + Web (Expo/React Native). 100% offline, sin cuentas, sin backend.

## Stack

| Categoría | Tecnología |
|---|---|
| Framework | React Native (Expo) |
| Lenguaje | TypeScript (`strict: true`) |
| Estado | Zustand + persist |
| Animación | react-native-reanimated + worklets |
| Gráficos | react-native-svg |
| Audio | expo-audio |
| Gestos | react-native-gesture-handler |
| Persistencia | AsyncStorage / localStorage |
| Web | react-native-web |
| Lint/Format | ESLint + Prettier |

## Desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar
npx expo start
```
